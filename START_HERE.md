# Start Here

1. Install `requirements.txt` in a Python virtual environment.
2. Run `python tools/verify.py`.
3. Create a private instance with `python tools/init_instance.py INSTANCE_PATH`.
4. Set `PROJECT_ANISSA_INSTANCE` to that path.
5. Complete onboarding and inspect `python tools/preflight.py`.
6. Bind persistent role chats and scheduled work only after explicit go-live
   authorization.

The generated workbook is the only mutable agenda record. Do not create a
second task database or place personal documents in this repository.
